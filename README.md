# Дениско пиписко и Миланка милашка

Веб-приложение для синхронного просмотра видео на расстоянии. Один пользователь даёт ссылку на страницу с фильмом, приложение пытается извлечь медиаплеер, после чего все участники комнаты видят один и тот же плеер и могут ставить на паузу, перематывать — состояние синхронизируется у всех в реальном времени. Поддерживается полноэкранный режим.

## Локальный запуск

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Откройте http://127.0.0.1:8000

## Деплой на Render

1. Загрузите репозиторий на GitHub.
2. В Render создайте Web Service из репозитория.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
5. После деплоя откройте выданный URL.

Файлы `Procfile`, `railway.json`, `runtime.txt` оставлены для Railway/Heroku — они не мешают.

### Переменные окружения
Никаких обязательных переменных нет. Порт берётся из `$PORT`.

## Как пользоваться

1. Откройте сайт, вставьте ссылку на страницу с фильмом, нажмите «Отправить ссылку» (или Enter) — создастся комната.
2. Скопируйте ссылку комнаты (кнопка «Скопировать ссылку») и отправьте подруге.
3. Подруга открывает ссылку — подключается к той же комнате.
4. Управление (play/pause/перемотка) синхронизируется у всех.
5. Кнопка ⛶ или двойной клик по видео — полноэкранный режим. Клавиша `F` — тоже.

## Ограничения

Извлечение плеера зависит от сайта-источника:
- **YouTube, Rutube** — синхронизация работает (плеер управляется через API).
- **Прямые ссылки** (`.mp4`, `.m3u8`, `.webm`) — синхронизация работает.
- **Kinobox-сайты** (kinogo, fixtyflux и подобные) — сервер находит прямую ссылку на видео (обычно через плеер Collaps) и отдаёт её через внутренний HLS-прокси, синхронизация работает. Если прямую ссылку найти не удалось (например, на сайте только плеер Alloha), страница плеера встраивается в iframe — тогда синхронизации нет, каждый управляет сам.
- **Другие сайты** — если медиа не извлечь, страница встраивается в iframe (просмотр без синхронизации).

Для гарантированной синхронизации используйте YouTube, Kinobox-сайты или прямые ссылки на видеофайлы.

## Заметки

- Видео с HLS-потоками (`.m3u8`) загружается через `/api/hls?url=...` — сервер забирает плейлисты и сегменты сам, это обходит CORS и блокировки CDN по User-Agent.
- Комнаты хранятся в памяти процесса: после перезапуска сервера существующие комнаты исчезают, нужно отправить ссылку заново.
- **Синхронизация как в Rave**: сервер — единый источник правды. Он хранит «эталонную» позицию воспроизведения и каждые 2,5 секунды рассылает её всем зрителям. Клиент сверяет свою позицию с серверной: расхождение больше 2,5 с — жёсткий переход на позицию комнаты (догнать после буферизации, позднее подключение, подвисание); небольшое расхождение — плавная подгонка скоростью (до ±8%); пока видео не прогрузилось — клиент ждёт и по готовности встаёт на актуальную позицию. Перемотка рассылается сразу при намерении (событие `seeking`), поэтому остальные зрители прыгают на новое место мгновенно, не дожидаясь, пока у автора перемотки докачаются сегменты.
