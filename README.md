# Дениско пиписко и Миланка милашка

Веб-приложение для синхронного просмотра видео на расстоянии. Один пользователь даёт ссылку на страницу с фильмом, приложение пытается извлечь медиаплеер, после чего все участники комнаты видят один и тот же плеер и могут ставить на паузу, перематывать — состояние синхронизируется у всех в реальном времени. Поддерживается полноэкранный режим.

## Локальный запуск

```bash
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Откройте http://127.0.0.1:8000

## Деплой в Railway

1. Создайте новый проект в Railway и подключите этот репозиторий (или загрузите файлы).
2. Railway автоматически определит Python-проект по `requirements.txt` и `Procfile`.
3. Команда запуска: `uvicorn main:app --host 0.0.0.0 --port $PORT` (уже указана в `Procfile`/`railway.json`).
4. После деплоя откройте выданный URL.

### Переменные окружения
Никаких обязательных переменных нет. Порт берётся из `$PORT`.

## Как пользоваться

1. Откройте сайт, вставьте ссылку на страницу с фильмом, нажмите «Создать комнату».
2. Скопируйте ссылку комнаты (кнопка «Скопировать ссылку») и отправьте подруге.
3. Подруга открывает ссылку — подключается к той же комнате.
4. Управление (play/pause/перемотка) синхронизируется у всех.
5. Кнопка ⛶ или двойной клик по видео — полноэкранный режим. Клавиша `F` — тоже.

## Ограничения

Извлечение плеера зависит от сайта-источника:
- **YouTube, Rutube** — синхронизация работает (плеер управляется через API).
- **Прямые ссылки** (`.mp4`, `.m3u8`, `.webm`) — синхронизация работает.
- **Kinobox-сайты** (kinogo и подобные) — видео загружается, но синхронизация недоступна (плеер встроен в iframe стороннего сервиса). Каждый участник управляет плеером сам.
- **Другие сайты** — если медиа не извлечь, страница встраивается в iframe (просмотр без синхронизации).

Для гарантированной синхронизации используйте YouTube или прямые ссылки на видеофайлы.
